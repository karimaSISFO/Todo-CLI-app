# Todo CLI App

A simple terminal-based todo manager written in Python.

## Features
- Add, list, delete, and complete tasks
- Priority levels: HIGH, MED, LOW
- Persist tasks to a local file
- Sort tasks by priority

## Usage

python todo.py


## Commands
| Command | Action              |
|---------|---------------------|
| add     | Add a new task      |
| list    | List all tasks      |
| done    | Mark task complete  |
| del     | Delete a task       |
| save    | Save tasks to file  |
| quit    | Exit the program    |
